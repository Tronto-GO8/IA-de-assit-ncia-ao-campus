ACESSO AO DIPLOMA DIGITAL PARA DISCENTES
TUTORIAL SIGAA

Neste tutorial, você aprenderá como emitir o seu Diploma Digital.
Para isso, siga atentamente os passos descritos a seguir.
1. Acesse o “Portal Discente”.

2. Clique no Menu “Ensino”.
3. Clique em “Impressão de Diploma Digital”.

4. Clique no ícone “lupa” para visualizar os
dados do seu Diploma Digital.

SOBRE
5. Clique no botão “Download PDF
Diploma” para baixar o seu Diploma
Digital em formato PDF.
Observação: Se desejar baixar o seu diploma em
formato XML, clique no botão “Download XML
Assinado”. Este formato é usado para validação
automática pelos sistemas do MEC e das
Universidades.

Importante!
1) PDF do diploma digital: é a versão visual do diploma — igual a um diploma impresso, mas em formato
eletrônico. Serve para você ver e mostrar o documento.
2) XML do diploma digital: é a versão técnica, com todas as informações oﬁciais do diploma (como nome, curso,
data e autenticação). Serve para validação automática pelos sistemas do MEC e das universidades.
Resumindo: o PDF é a imagem do diploma para leitura humana, e o XML é o arquivo oﬁcial usado pelos sistemas
para conﬁrmar a validade.
